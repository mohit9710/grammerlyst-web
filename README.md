# Grammrlyst

AI-powered English fluency platform — speaking practice, pronunciation training, grammar lessons, writing tools, and vocabulary games, built with Next.js.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app. The dev server proxies `/api/backend/*` to a local backend running on `http://127.0.0.1:8000` (see `next.config.ts`).

## Scripts

- `npm run dev` — start the development server
- `npm run build` — production build
- `npm run start` — run the production build
- `npm run lint` — run ESLint
